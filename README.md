# Мастерская

Сайт дома творчества. Практическая работа «Адаптация сайта».

Лендинг каталога переведён на тему мастерской. Кружки, люди и расписание берутся из базы `masterskaya`. Подсчёт людей использует функции из практической №1, бюджет — трекер расходов из практической №2.

## Запуск

```bash
npm install
npm start
```

Сайт откроется на http://127.0.0.1:4173

Если PostgreSQL с базой `masterskaya` доступен локально, страницы читают его. Иначе показываются те же записи из `schema.sql`. Подключение можно задать переменными `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`.

Пароли пользователей на сайт не выводятся.
